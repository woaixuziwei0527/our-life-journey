# 💕 Our Life Journey - 情侣旅行地图

一个专为异地恋情侣设计的 3D 旅行记录网站，用蓝粉梦幻配色记录你们一起走过的城市。

## ✨ 功能特性

- 🗺️ **3D 中国地图** - 暗夜星空背景，可视化展示旅游城市
- ⭐ **城市点亮** - 去过的城市可以点亮标记
- 📝 **旅行记录** - 为每个城市添加文字和照片（最多 3 张）
- 📅 **时光轴** - 按时间顺序回顾所有旅行记录
- 💌 **留言功能** - 在特定城市给对方留言
- 📊 **统计面板** - 查看一起去过的城市数、照片数等
- 📱 **手机适配** - 完美支持手机端浏览
- 🔐 **私密登录** - 共享密码登录，内容仅两人可见

## 🎨 设计特色

- **配色**: 梦幻蓝粉渐变（#38bdf8 → #f472b6）
- **背景**: 暗夜星空 + 玻璃态面板
- **图标**: 精致 SVG 卡通小人
- **动画**: 星星闪烁、漂浮、发光效果

## 🚀 快速开始

### 1. 本地开发

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev
```

访问 http://localhost:5173 查看

### 2. 部署到 Vercel（推荐）

```bash
# 安装 Vercel CLI
npm install -g vercel

# 部署
vercel
```

或直接在 Vercel 官网导入 GitHub 仓库自动部署。

### 3. 配置 Supabase（可选，用于云存储）

1. 访问 [supabase.com](https://supabase.com) 创建免费项目
2. 获取项目 URL 和 Anon Key
3. 复制 `.env.example` 为 `.env`
4. 填入你的 Supabase 配置

**当前版本使用 LocalStorage 存储数据**，无需配置后端即可使用！

## 📱 使用流程

1. **登录** - 输入共享密码进入
2. **浏览地图** - 查看 3D 中国地图和城市标记
3. **添加记录** - 点击城市星标 → 填写标题、内容、上传照片
4. **查看时光轴** - 按时间回顾所有旅行
5. **留言互动** - 在留言箱给 TA 写信
6. **查看统计** - 了解你们的旅行数据
